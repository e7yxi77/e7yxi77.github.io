# 하루펫택시 웹사이트

반려동물 전용 이동 서비스 **하루펫(하루펫택시)** 의 소개 사이트입니다.
네이버 톡톡 프로필([talk.naver.com/profile/w5xpj1](https://talk.naver.com/profile/w5xpj1))의
서비스명·색상·서체·연락처·요금표를 그대로 옮겨 왔습니다.

- 서버 없이 동작하는 **정적 사이트**입니다. 백엔드·데이터베이스·빌드 과정이 없습니다.
- 외부 라이브러리를 쓰지 않습니다. HTML·CSS·JavaScript 파일 세 개가 전부입니다.
- 예약은 전화(`tel:`)와 네이버 톡톡 링크로 연결됩니다. 폼 전송이 없으므로 개인정보를 저장하지 않습니다.

```

```

## GitHub Pages 배포

1. GitHub 에서 새 저장소를 만듭니다.
2. 이 폴더의 **내용물 전체**를 저장소 루트에 올립니다. (`index.html` 이 최상단에 있어야 합니다.)
   ```bash
   git init
   git add .
   git commit -m "하루펫택시 웹사이트"
   git branch -M main
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages** 로 이동합니다.
4. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/ (root)` 로 지정하고 저장합니다.
5. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

> 현재 배포 주소는 **https://ey.io.kr/20260822/** 입니다.
> (저장소 `e7yxi77/e7yxi77.github.io` 의 `20260822/` 폴더, 루트 `CNAME` 이 `ey.io.kr`)
> 주소가 바뀌면 `index.html` 의 `canonical` · `og:url` · `og:image` · JSON-LD `url` 네 곳을 함께 고쳐야 합니다.

### 도메인을 연결하려면

1. 저장소 루트에 `CNAME` 파일을 만들고 도메인만 한 줄 적습니다. 예: `harupet.co.kr`
2. 도메인 관리 화면에서 아래 A 레코드 네 개를 추가합니다.
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. **Settings → Pages → Custom domain** 에 같은 도메인을 입력하고 `Enforce HTTPS` 를 켭니다.

### 로컬에서 미리 보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

**교체 요령**

- 사진은 화면을 꽉 채우도록 잘려서(`object-fit: cover`) 보입니다. **인물이나 동물은 가운데**에 두세요.
- 파일 용량은 장당 **300KB 이하**를 권합니다. 느린 모바일에서도 빨리 열립니다.
- 확장자를 바꾸고 싶다면(`.jpg` → `.webp` 등) `index.html` 의 `src` 도 함께 바꿔야 합니다.
- 사진을 더 넣고 싶다면 `index.html` 에서 해당 `<img>` 태그의 `src` 와 `alt` 를 수정하세요.
- 서비스 항목의 사진은 `<div class="acc-item" data-photo="images/...">` 의 `data-photo` 값이 결정합니다.

### 화면 폭에 따른 차이

| | 데스크톱 (901px~) | 모바일 (~900px) |
| --- | --- | --- |
| 구조 | 좌우 두 트랙이 반대 방향으로 흐르는 5구간 | 위에서 아래로 읽는 한 줄 문서 |
| 상단 바 | 높이 74px, 배경 `--paper` | 높이 60px, 배경 `--paper` |
| 상단 바 내용 | 견적 신청서 · 네이버 톡톡 (텍스트) + 전화번호 (버튼) | 견적 · 톡톡 (텍스트) + 전화 예약 (버튼) |
| 견적 요청 | 입력(좌) + 미리보기(우) | 크림 배경 한 덩어리로 묶어 입력 → 미리보기 순서 |
| 사진 라벨 | 사진 위에 떠 있는 알약 | 사진 아래 캡션 줄 (겹침 없음) |
| 이동 | 한 번 스크롤에 한 구간씩 (스냅) · 키보드 · 우측 화살표 | 일반 스크롤 |

상단 바는 **채워진 버튼 하나(전화)** 와 **텍스트 링크 둘(견적 · 톡톡)** 로 구성했습니다.
톡톡만 네이버 초록으로 두어, 색을 늘리지 않고도 어떤 채널인지 알 수 있게 했습니다.

상단 바 높이는 `:root` 의 `--bar-h` 하나로 관리합니다. 값을 바꾸면 본문 여백,
주행선 시작 위치, 앵커 스크롤 보정(`scroll-margin-top`)이 함께 따라갑니다.

### 견적 요청서

가격은 사이트에 표시하지 않습니다. 이용자가 이동 정보를 입력하면 **견적 요청서**가 만들어지고,
그걸 복사하거나 내려받아 네이버 톡톡·카카오톡으로 보내면 운영자가 금액을 안내하는 방식입니다.

**왜 이렇게 했나** — 출발지·도착지가 매번 달라서 자동 요금 계산을 하려면 실제 도로 거리가 필요한데,
길찾기 API 는 브라우저에서 직접 부를 수 없어 서버가 있어야 합니다. 직선거리로 대신 계산하면
실제보다 30% 가까이 차이 나서 안내 금액으로 쓰기 어렵습니다.

**입력 항목** — 이용 날짜 / 출발 시간 / 출발지 / 도착지 / 탑승 인원 /
소형견·중형견·대형견·고양이 마리수 / 짐 / 요청사항

**내보내는 방법 두 가지**

| | 무엇을 하나 | 어디에 좋은가 |
| --- | --- | --- |
| **내용 복사하기** | 정리된 글로 클립보드에 복사 | 모바일 — 톡에 붙여넣기만 하면 됨 |
| **견적서 다운로드** | 브라우저 인쇄 기능으로 A4 PDF 저장 | PC — 파일로 보관·전달 |

PDF 는 별도 라이브러리 없이 브라우저 인쇄 기능을 씁니다. 한글이 깨지지 않고 용량도 작습니다.
양식은 `index.html` 맨 아래 `.quote-sheet` 와 `styles.css` 의 `@media print` 블록에 있습니다.

주소 입력은 **다음 우편번호 서비스**를 씁니다. API 키가 필요 없고 무료이며,
스크립트를 못 불러오는 환경에서는 주소를 직접 입력할 수 있게 자동으로 풀립니다.

입력 내용은 **어디에도 전송·저장되지 않고** 이용자 브라우저 안에서만 처리됩니다.

## 확인이 필요한 항목

작업하면서 네이버 톡톡 프로필과 안내 이미지에서 가져온 내용 중, 운영자 확인이 필요한 부분입니다.

1. **전화번호 두 개** — 톡톡 프로필에는 `010-7987-3460`, 장거리 안내 이미지에는 `010-8030-7236` 이 적혀 있어
   앞의 번호를 대표 번호로, 뒤의 번호를 "장거리 상담" 으로 표기했습니다.
2. **이용 절차 5단계** — 안내 이미지에 절차가 명시되어 있지 않아 일반적인 흐름으로 작성했습니다.
3. **견적 요청 항목** — 짐 선택지(이동장·유모차·캐리어)와 요청사항은 임의로 구성했습니다. 실제 상담에서 필요한 항목이 더 있으면 알려주세요.

## 접근성과 호환성

- 모바일(가로 900px 이하)에서는 좌우 트랙이 풀리고 위에서 아래로 읽는 한 줄 문서가 됩니다.
  각 구간은 "설명 → 사진" 순서로 정렬되고, 지방 요금표는 선택한 요일 한 칸만 보여 줍니다.
- **상단 고정 바 하나**(하루펫 · 전화 예약 · 네이버 톡톡)가 유일한 상시 행동 버튼입니다.
  같은 버튼을 본문에서 반복하지 않도록 히어로의 전화 버튼은 모바일에서 감춥니다.
- 견적 요청 구간은 입력과 미리보기를 하나의 크림 블록으로 묶어, 채우는 즉시
  바로 아래에서 요청서가 완성되는 것이 보입니다.
- 360px 폭까지 가로 스크롤 없이 표시됩니다.
- 데스크톱은 **한 번 스크롤할 때마다 한 구간씩** 화면에 딱 맞게 넘어갑니다.
  트랙패드 관성으로 여러 구간이 지나가지 않도록 한 동작당 한 번만 받습니다.
  (`script.js` 의 `peakSince` 방식 — 마지막 이동 이후 가장 셌던 세기보다 더 세게 밀렸을 때만 넘어갑니다)
- 키보드 : `↑` `↓` `PageUp` `PageDown` `Space` `Home` `End` 로 구간을 이동합니다.
- 운영체제의 "동작 줄이기" 설정을 켜면 모든 애니메이션이 꺼집니다.
- 자바스크립트를 꺼도 모든 내용을 읽을 수 있습니다.
- `#block-0` ~ `#block-4` 를 주소 뒤에 붙이면 해당 구간으로 바로 열립니다. (예: 견적 요청은 `#block-3`)
